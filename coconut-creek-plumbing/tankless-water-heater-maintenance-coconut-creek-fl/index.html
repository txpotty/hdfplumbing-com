    Tankless Error Code Diagnosis in Coconut Creek, FL

    An error code is the heater telling you what it saw. On a Rinnai an LC code means scale, on a Navien E003 means no ignition, and on a Noritz a 90 usually means an air or exhaust problem. We pull the code history before touching anything. If a part has failed, you hear the repair and the price before we start.

    Step-by-Step Tankless Flushing in Coconut Creek

    First we shut off the gas and power, then close both isolation valves so the heater is cut off from the house plumbing. Solution goes from a bucket into the cold port, out the hot port and back to the bucket. Once the cycle ends, we rinse with clean water and pull the inlet screen. Then we check for leaks.

    Annual Tankless Checkup in Coconut Creek, FL
