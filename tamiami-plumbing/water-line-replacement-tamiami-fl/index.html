    Copper Service Line Installation in Tamiami, FL

    Copper is still the choice for some homeowners. Plenty of copper mains have lasted 60 years.     PEX Water Line Installation in Tamiami, FL

    PEX bends around corners, so a typical service run needs no fittings between the meter and the house. We still bury it below the frost depth the local code sets, and keep it covered from sunlight at the meter box, since UV light breaks it down. Short exposure only.

    Type L vs. Type K Copper in Tamiami, FL

    The thickest wall belongs to Type K, the usual choice underground. Type L is thinner and mostly used inside the house. Some codes allow L for burial, but we stick with K for service lines because a thicker wall buys more years against corrosive soil and stray rocks. Same fittings, different pipe.
