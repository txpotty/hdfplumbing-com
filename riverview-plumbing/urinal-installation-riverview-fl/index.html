    Residential Urinal Plumbing in Riverview, FL

    Home urinals use the same rules as commercial ones. The drain is usually 2 inch, the trap is built into the china, the fixture needs a vent within code distance, and the flush valve needs either a 3/4 inch supply or a lower-flow residential valve on 1/2 inch. Permit rules apply too. We check that first.

    Flushometer Urinal Installation in Riverview

    Manual flushometers are still the most common setup. Manual valves go on a 3/4 inch line with the control stop tuned and the vacuum breaker at the correct height. Handle side follows the layout. ADA units need the handle within reach.

    Waterless Urinal Installation in Riverview

    Waterless urinals save the most water and need the most discipline. They use a cartridge or a layer of sealing liquid that lets urine pass while blocking sewer gas, and the cartridge has to be swapped on schedule or the restroom starts to smell. Cleaning staff need a quick lesson. We show them how.

    Drainage and Venting for Urinals in Riverview, FL

    Urinal drains clog with scale, not paper. Low-flow and waterless units leave mineral buildup in the line, so proper slope and a cleanout matter. A proper vent keeps odor out. We tie in within code distance.

    Rough-In Plumbing for Urinals in Riverview, FL

    Rough-in decides whether the finish goes smoothly. We set the carrier, run a 2 inch waste line to the outlet height on the spec sheet, stub the 3/4 inch supply where the flush valve will land, and tie the vent in before anyone hangs drywall. The rough gets inspected before cover. Then the walls close.

    Sensor Urinal Installation in Riverview, FL

    Sensor valves stop missed flushes and double flushes. We install battery or hardwired units, set the sensing range so the valve does not fire when someone walks past, and turn on a sanitary flush cycle if the restroom sits empty for long stretches. Batteries last a few years. Hardwired units need an electrician first.

    ADA Urinal Installation in Riverview

    Accessible urinals start at the carrier. We set the carrier so the finished rim lands at 17 inches or lower, keep the clear floor space free of partitions and door swings, and mount the flush handle or sensor where a seated user can reach it. Measurements get checked twice. Inspectors measure too.

    Sloan Flush Valve Installation in Riverview, FL

    Sloan Royal valves are on most commercial urinals we see. Each Sloan Royal gets the right inside parts for the bowl, a tuned control stop and a rebuild kit on hand. Sensor versions mount the same way. Battery models need no wiring.
